# 黑白视觉系统说明 v0.7

更新时间：2026-07-21

## 1. 设计方向

v0.7 将界面从小羊 mascot 与彩色主题切换为黑白灰工具型视觉。设计目标是降低装饰感，突出录音、任务和确认信息，让产品更接近移动端效率工具。

核心原则：

- 手机界面以纯白为基础，内容区使用中性浅灰。
- 主要操作、选中导航和品牌标记使用炭黑。
- 卡片保持白色，通过细边框和轻阴影区分层级。
- 常规状态使用不同明度的灰色，不依赖彩色装饰。
- 仅在录音、删除或错误等必须提示风险的场景保留警示色。
- 小羊图片、背景装饰和表情贴纸不再进入运行时界面。

## 2. 颜色基准

| 用途 | 色值 |
| --- | --- |
| 页面底色 | `#FFFFFF` |
| 内容区底色 | `#F7F7F7` |
| 主文字 / 主操作 | `#171717` |
| 次级文字 | `#5F5F5F` |
| 弱文字 | `#929292` |
| 分隔线 | `#ECECEC` |
| 选中或弱强调底色 | `#EEEEEC` |

颜色变量以 `app/globals.css` 和 `tailwind.config.ts` 为准，页面组件不得重新引入大面积品牌色。

## 3. 品牌标记

当前品牌标记为抽象“声波—行动”图形，由声波折线与确认笔画组合而成：

- React 组件：`components/BrandMark.tsx`
- PWA / favicon：`public/brand/app-icon.svg`
- 首页、空状态、处理状态和安装入口统一使用该标记
- 标记不承载人物、动物或情绪角色设定

## 4. 页面结构

- 首页：白色顶部品牌区、浅灰内容区、白色概览卡片和录音主卡片。
- 任务 / 历史：白色标题栏、浅灰列表背景、白色任务卡片。
- 我的：白色身份卡片、统计卡片和设置列表。
- 底部导航：白底，选中项使用浅灰底与炭黑图标。
- 弹层：优先白底与中性灰分隔，主操作使用炭黑按钮。

## 5. PWA 与缓存

Manifest 的 `theme_color` 与 `background_color` 均为白色。Service Worker v0.7 只预缓存当前黑白 SVG 品牌图标，不再预缓存历史小羊资源。

## 6. 兼容说明

`sheep_record`、`sheep_think`、`sheep_done`、`sheep_warn` 等内部标签 ID 暂时保留，以兼容已有 JSON 数据；用户可见名称已经调整为“已记录、处理中、已完成、待确认”。历史小羊素材仍保留在仓库中，但不被页面或 PWA 运行时引用。
